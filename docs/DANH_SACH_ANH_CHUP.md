# DANH SÁCH ẢNH CHỤP MÀN HÌNH CẦN BỔ SUNG VÀO BÁO CÁO

Cách chụp: chạy website, bấm **Win + Shift + S** (Snipping Tool), kéo chọn vùng, lưu PNG. Nên để trình duyệt rộng khoảng 1280px, phóng 100%, chụp cả thanh địa chỉ. Trong file báo cáo DOCX, mỗi vị trí có khung "[CHÈN ẢNH ...]": xóa khung và chèn ảnh (Insert → Pictures).

| STT | Mục báo cáo | Chụp gì | Điều kiện |
|---|---|---|---|
| 1 | 1.3 Cài đặt | Kết quả `check-connection.php` (tất cả OK) | Sau khi cài driver |
| 2 | 1.3 Cài đặt | Dữ liệu trong SSMS (cây bảng Users, Categories, Books, Orders, OrderDetails) | Sau khi chạy `bookstore.sql` |
| 3 | 2.2 CSDL | (tùy chọn) Database Diagram của SSMS | Có thể chụp thêm |
| 4 | 3.1.1 Chương trình chính | Toàn bộ trang chủ (chụp 2 ảnh nếu dài) | Chưa đăng nhập |
| 5 | 3.1.2 Đăng nhập | Trang đăng nhập; thêm ảnh thông báo lỗi khi sai mật khẩu | |
| 6 | 3.1.3 Đăng ký | Trang đăng ký; thêm ảnh báo lỗi kiểm tra dữ liệu | |
| 7 | 3.1.4 Danh mục và danh sách sách | Trang `books.php` có bộ lọc; ảnh kết quả tìm kiếm | |
| 8 | 3.1.5 Giỏ hàng | Trang giỏ hàng có 2 sản phẩm | |
| 9 | 3.1.6 Quản lý sách (Admin) | Danh sách sách Admin; biểu mẫu thêm sách | Đăng nhập admin |
| 10 | 3.1.7 Chi tiết sách | Trang chi tiết một cuốn còn hàng | |
| 11 | 3.1.8 Đặt hàng | Trang đặt hàng; trang chi tiết đơn sau khi đặt | Đăng nhập khách hàng |
| 12 | 3.1.9 Lịch sử đơn hàng | Danh sách đơn của khách | |
| 13 | 3.1.10 Dashboard | Trang tổng quan Admin | |

| 15 | 3.1.12 Quản lý đơn hàng | Danh sách đơn; chi tiết đơn có ô cập nhật trạng thái | |
| 16 | 3.2.1 Kết quả kiểm thử | Bảng kiểm thử đã điền kết quả (Bảng 3.2 trong Word) | Sau khi chạy kịch bản |

Mẹo: dùng đúng các dữ liệu mẫu để ảnh nhìn nhất quán; có thể thêm vài sách bằng trang Admin trước khi chụp.
